## Technical skills

- requirements and sizing: CPU/GPU, storage volumes and types, network latency
- logical and physical architecture: OLTP (normalized, ACID), OLAP (star schema), NoSQL document model
- hosting trade-offs: cloud, on-premise or hybrid; IaaS, PaaS or serverless; data sovereignty
- Infrastructure as Code: reproducibility, idempotence, modules, versioning, plan/lint/security scans
- storage and execution environments: data lake, vector database, container orchestration
- resilience: auto-scaling, failover, continuity scenarios
- security by design: IAM/RBAC, encryption, network segmentation, secret management
- FinOps / GreenOps, monitoring, accessible operations documentation

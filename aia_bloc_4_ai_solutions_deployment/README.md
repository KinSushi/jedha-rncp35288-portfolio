## Technical skills

- model lifecycle automation: CI/CD/CT, validation tests before any update, model and data versioning with rollback
- inference architecture: real time or batch, containers and orchestration under load, caching
- progressive rollout (A/B, canary) and production observability: data and prediction drift, alerts, automated retraining
- operational and economic efficiency: resource usage, FinOps, sustainability
- ethics and regulation: explainability, guardrails against bias, EU AI Act risk assessment
- technical documentation: architecture dossier, model card, API documentation, runbooks

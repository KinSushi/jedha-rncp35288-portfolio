# Certification Mapping

## Purpose

This document maps public technical evidence to two certification structures: the six-block RNCP35288 Data Science track (Level 6) and the four-block RNCP38777 AI Architect track (Level 7, renewed as RNCP41993).

It does not claim certification completion unless officially validated. It does not publish private documents.

## Six-block map — RNCP35288

| Block | Public folder | Evidence type |
|---|---|---|
| Bloc 1 — Data infrastructure | `bloc_1_data_infrastructure/` | SQL, ingestion, architecture, quality controls |
| Bloc 2 — EDA/statistics | `bloc_2_eda_statistics/` | EDA, distributions, statistical analysis, reports |
| Bloc 3 — Machine learning | `bloc_3_machine_learning/` | training, evaluation, explainability, metrics |
| Bloc 4 — NLP/deep learning | `bloc_4_nlp_deep_learning/` | NLP, text classification, RAG foundations |
| Bloc 5 — Industrialization/MLOps | `bloc_5_mlops_deployment/` | API, Docker, CI, monitoring, MLflow |
| Bloc 6 — Project governance | `bloc_6_project_governance/` | project charter, risk register, data/model cards |

## Four-block map — RNCP38777 (AI Architect)

| Block | Public folder | Evidence type |
|---|---|---|
| AIA Bloc 1 — Data & AI governance | `aia_bloc_1_data_ai_governance/` | governance plan, RACI, data contracts, access policy, regulation (GDPR, EU AI Act) |
| AIA Bloc 2 — AI data architecture | `aia_bloc_2_ai_data_architecture/` | architecture plan, data models, Infrastructure as Code, video of the running infrastructure |
| AIA Bloc 3 — Data pipelines for AI | `aia_bloc_3_data_pipelines_for_ai/` | pipeline plan, orchestration code, quality gates, video of the running pipeline |
| AIA Bloc 4 — AI solutions deployment | `aia_bloc_4_ai_solutions_deployment/` | solution presentation, development and deployment code with CI/CD, monitoring, video in production |

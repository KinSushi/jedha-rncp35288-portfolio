# Public Safety Rules

## Forbidden

- private Jedha course files;
- exam subjects or answers;
- grades;
- private certificates with identifiers;
- CPF documents;
- contracts;
- invoices;
- CVs and cover letters;
- job trackers;
- recruiter messages;
- salary strategy;
- real banking, insurance, health, client or employer data;
- secrets or credentials.

## Allowed

- code written by the repository owner;
- synthetic or open data;
- sanitized screenshots;
- architecture diagrams;
- model cards;
- data cards;
- runbooks;
- governance documents;
- evidence indexes.

## Pre-push checklist

- [ ] no private school material;
- [ ] no application material;
- [ ] no personal identifiers in certificates/screenshots;
- [ ] no real client or employer data;
- [ ] no secrets;
- [ ] public wording is conservative and accurate.

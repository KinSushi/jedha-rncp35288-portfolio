# Validation

## Purpose

This file documents structure and public-safety validation for this repository.

Required public files:

```text
README.md
PORTFOLIO.md
docs/evidence_index.md
docs/public_safety_rules.md
bloc_1_data_infrastructure/README.md
```

## Private-document boundary

This public repository must not contain:

```text
private school documents
exam material
grades
certificates with personal identifiers
CPF or administrative documents
contracts or invoices
CVs or cover letters
job trackers
real client, employer, banking, insurance or health data
credentials or authentication material
```

## Review checklist

Before each push:

- required public files exist;
- six block folders exist;
- no private documents are present;
- no application material is present;
- no credentials are present;
- evidence index is updated when new artifacts are added.

## Portfolio rule

This repository is public technical evidence. It is not a private school archive and not an application dossier.

## Technical skills

- flow architecture: batch, streaming, ETL or ELT, chosen from the required data freshness
- ingestion sized for volume without loss: APIs, Kafka, change data capture
- layered transformations (bronze, silver, gold), feature engineering, historical reprocessing
- orchestration with explicit dependencies (Airflow DAGs), reproducible runs across environments
- data quality: schema validation at each step, dead-letter queues, retries
- privacy by design: masking or pseudonymization, externalized secrets, encryption in transit
- observability: SLA alerting, audit logs, data lineage, pipeline cost estimate
- delivery management: backlog, iterations, documentation a third party can take over

# Portfolio Review Checklist

## Technical completeness

- [ ] each block has a README;
- [ ] evidence index updated;
- [ ] external repositories linked where relevant;
- [ ] screenshots sanitized;
- [ ] code and reports are reproducible where possible.

## Public-safety

- [ ] no private school documents;
- [ ] no exam material;
- [ ] no grades;
- [ ] no CV/application content;
- [ ] no secrets;
- [ ] no real data.

## Recruiter readability

- [ ] each block explains what it proves;
- [ ] each artifact maps to technical skills;
- [ ] non-goals are explicit;
- [ ] repository is readable in 60 seconds.
